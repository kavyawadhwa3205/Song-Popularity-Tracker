# Song Popularity Tracker

## Project Overview
The Song Popularity Tracker is designed to analyze and visualize the popularity trends of various songs over a specified period. The project provides insights into how different factors influence song popularity and allows users to explore data related to the music industry.

## Features
- **Trend Analysis**: Visualize how song popularity changes over time.
- **Interactive Dashboards**: Engage with dynamic charts that represent data trends.
- **Customizable Reports**: Generate reports based on user-defined parameters.

## Data Sources
Songs data is sourced from popular music streaming platforms and charts, including:
- Spotify
- Billboard charts
- Apple Music

## Analysis Methods
We employ various data analysis techniques, including:
- Time series analysis
- Correlation metrics
- Regression analysis

## File Descriptions
- `data/`: Contains raw data files and processed datasets.
- `analysis/`: Houses the scripts for data analysis.
- `visualization/`: Includes scripts for generating visual reports and charts.
- `README.md`: Documentation for the project, explaining functionalities and usage.

## Getting Started
To set up the project locally:
1. Clone the repository: `git clone https://github.com/kavyawadhwa3205/Song-Popularity-Tracker.git`
2. Navigate to the project directory: `cd Song-Popularity-Tracker`
3. Install dependencies: `pip install -r requirements.txt`
4. Execute the analysis scripts as per the documentation.

## Insights and Findings
The analysis reveals trends in song popularity based on genre, release date, and artists. It highlights the impact of seasonal trends on song success and provides actionable insights for music marketers.
